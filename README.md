# Portal de Acesso - OAB/SC

Este projeto é um portal desenvolvido para facilitar o acesso dos advogados e advogadas aos principais serviços oferecidos pela **Ordem dos Advogados do Brasil - Seccional de Santa Catarina (OAB/SC)**.

## 🔗 Acesso ao Portal

**URL:** [https://portal.oab-sc.org.br](https://portal.oab-sc.org.br)

## 📜 Descrição

O portal foi criado para centralizar os serviços e proporcionar uma navegação mais rápida e prática para os profissionais da advocacia catarinense.

### Funcionalidades principais:

- 🎯 Acesso rápido aos setores:
  - Secretaria
  - Tesouraria
  - Conselho
  - Comissões
  - Consultas
  - Prerrogativas
  - Sociedades
  - Fiscalização
  - Tribunal de Ética e Disciplina (TED)
  - INSS Digital
  - Exame de Ordem
  - Cursos e Eventos
  - Controladoria
  - Tecnologia
- 🔍 Barra de pesquisa para facilitar a localização de serviços.
- 🖥️ Layout responsivo, adaptado para diferentes dispositivos.

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
